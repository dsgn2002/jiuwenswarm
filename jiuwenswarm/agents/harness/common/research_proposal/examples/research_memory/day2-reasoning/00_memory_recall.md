- Earlier session day1-agents (2026-10-12): Where do multimodal LLM agents fail when deciding which tool to call, forming the call, and using tool outputs, and which failure mode is the most tractable research target? Recommended direction: Verifying tool outputs against visual evidence.
  - Gap G1: Multimodal agents do not verify tool outputs against visual evidence: visual ignorance and false acceptance persist even with stronger embeddings, and training rewards check final answers rather than intermediate tool results.
  - Gap G2: Tool selection is evaluated separately from argument formation: retrieval benchmarks pre-annotate or isolate tools, and function-calling benchmarks offer a single function, so compounding errors across the choose-call-use chain are unmeasured.
  - Gap G3: Multimodal agents lack temporal and contextual grounding for tool use: they struggle with dynamic GUI content and their lookups depend on context such as memory that benchmarks do not model.
- Paper [arxiv:2302.04761] Toolformer: Language Models Can Teach Themselves to Use Tools (2023): Toolformer teaches a language model to decide which APIs to call, when, with what arguments, and how to use results, via self-supervised filtering of sampled calls.
- Paper [arxiv:2406.10819] GUI-World: A Video Benchmark and Dataset for Multimodal GUI-oriented Understanding (2024): GUI-World is a video benchmark covering six GUI scenarios to test multimodal models' understanding of dynamic, multi-step GUI content.
- Paper [arxiv:2503.01763] Retrieval Models Aren't Tool-Savvy: Benchmarking Tool Retrieval for Large Language Models (2025): ToolRet benchmarks tool retrieval: selecting useful tools from a 43k-tool corpus for 7.6k tasks.
- Paper [arxiv:2505.14246] Visual Agentic Reinforcement Fine-Tuning (2025): Visual-ARFT trains open-source vision-language models with reinforcement fine-tuning and verifiable rewards to search the web and write image-manipulation code, and introduces the MAT benchmark.
- Paper [arxiv:2509.18420] Instruction-Following Evaluation in Function Calling for Large Language Models (2025): IFEval-FC tests whether models follow format instructions embedded in function-parameter descriptions.
- Paper [arxiv:2510.01253] OR-Toolformer: Modeling and Solving Operations Research Problems with Tool Augmented Large Language Models (2025): OR-Toolformer fine-tunes Llama-3.1-8B to call external operations-research solvers.
- Paper [arxiv:2607.09822] Memory-Conditioned Tool Calling for Camera-First Visual Agents (2026): Studies whether personal visual memory improves tool choice and arguments for camera-first agents that receive only an image.
- Paper [arxiv:2609.31718] MM-VeriRec: Failure-Guided Fusion for Verifiable Agentic Multimodal Recommendation (2026): MM-VeriRec verifies agentic multimodal recommendations against deterministic visual attributes and uses a failure taxonomy to route repairs.
