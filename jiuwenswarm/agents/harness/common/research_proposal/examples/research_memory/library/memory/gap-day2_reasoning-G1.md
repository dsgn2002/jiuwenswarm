# Open gap G1 from session day2-reasoning

Whether reasoning steps actually depend on the tool results they cite is untested: rewards check final answers or executable outcomes, and faithfulness work covers solver-executed chains, not interleaved tool use.

Context: When LLMs interleave long reasoning with tool calls, how far do their reasoning steps actually check and depend on intermediate tool results, and can process-level rewards make reasoning verify tool outputs rather than only reach correct final answers?
