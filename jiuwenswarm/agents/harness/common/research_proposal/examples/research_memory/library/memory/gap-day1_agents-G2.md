# Open gap G2 from session day1-agents

Tool selection is evaluated separately from argument formation: retrieval benchmarks pre-annotate or isolate tools, and function-calling benchmarks offer a single function, so compounding errors across the choose-call-use chain are unmeasured.

Context: Where do multimodal LLM agents fail when deciding which tool to call, forming the call, and using tool outputs, and which failure mode is the most tractable research target?
