# Open gap G1 from session day1-agents

Multimodal agents do not verify tool outputs against visual evidence: visual ignorance and false acceptance persist even with stronger embeddings, and training rewards check final answers rather than intermediate tool results.

Context: Where do multimodal LLM agents fail when deciding which tool to call, forming the call, and using tool outputs, and which failure mode is the most tractable research target?
