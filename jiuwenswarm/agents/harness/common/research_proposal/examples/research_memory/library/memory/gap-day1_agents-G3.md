# Open gap G3 from session day1-agents

Multimodal agents lack temporal and contextual grounding for tool use: they struggle with dynamic GUI content and their lookups depend on context such as memory that benchmarks do not model.

Context: Where do multimodal LLM agents fail when deciding which tool to call, forming the call, and using tool outputs, and which failure mode is the most tractable research target?
